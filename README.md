Productivity Hub
The Productivity Hub is an ALL IN ONE productivity dashboard, built with HTML, CSS, and Javascript!

Features
Subject System
- Subject specific notes, tasks, goals, habits, and journals
- Create custom folders/subjects
- Automatic general folder (for all topics combined)
  
Task Manager
- Complete, add, and delete tasks
- Progress tracking
- Completion analytics

Goals
- Create and complete goals
- XP rewards for goal completion

Habit Tracker
- Track daily habits
- Habit completion statistics

Notes
- Notes are seperated per/by subject
- Save notes using local storage!

Daily Journal
- Journal entries for EACH subject
- Automatically saved locally in storage

Pomodoro Timer
- 25 Minute focus timer
- Puase, start, and reset functionality

Focus tools
- Built in white noise sound generation
- Generation of motivational quote system

Gamification logic and strategies
- XP and leveling system
- Achievements
- Daily streak tracking

Analytics Dashboard
- Habits complete
- Focus score
- Tasks completed
- Weekly report
- Completion rate
- Productivity insights

  Study Planner
  - Schedule study sessions
  - Persistent local storage
 
  Themes
  - Ocean theme (to match white noise)
  - Light theme
  - Dark theme
 
    Technology used
    HTML5, CSS3, JavaScript, Local Storage API, and Canvas Confetti

    Data Storage: ALL user data is stored locally in the browser using local storage. No account/internet connection is required to use the website
